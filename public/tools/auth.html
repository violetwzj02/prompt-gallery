① Google Drive点一次，弹窗里点「允许」

用相册同一个 OAuth 客户端申请 drive.file 权限，约 1 小时有效。 过期了回本页再点一次即可。

③ Grok 登录态只能手工复制

        

          Grok 的 sso cookie 是 httpOnly，网页脚本读不到，必须从开发者工具里复制：
        

        
    
          
  1. 新标签打开 grok.com 并确认已登录
    2. 
          
  2. 按 F12 → Application（应用）→ 左侧 Cookies → https://grok.com
    3. 
          
  3. 找到 sso 和 sso-rw 两行，双击 Value 列全选复制
    4. 
          
  4. 按 sso=<值>; sso-rw=<值> 的格式贴给我
    5. 
        

      


      

        
④ 一键打包能拿到的部分合成一段

        
把 ①② 的结果合成一段 JSON，复制后整段发我即可（Grok 那段仍需你手工补）。
